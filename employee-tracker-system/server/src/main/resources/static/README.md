# WorkTracker PWA - Приложение для сотрудников

## 📱 Что это такое
Progressive Web App (PWA) для сотрудников системы учета рабочего времени. Работает как нативное приложение на телефоне.

## 🚀 Как установить

### На Android:
1. Откройте `http://localhost:8080` в Chrome
2. Нажмите меню (три точки) → "Установить приложение" или "Добавить на главный экран"
3. Подтвердите установку
4. Приложение появится на главном экране

### На iOS:
1. Откройте `http://localhost:8080` в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Выберите "На экран «Домой»"
4. Подтвердите добавление

## 📋 Функции

### Регистрация
- Введите ФИО, выберите должность, задайте пароль
- Данные отправляются на Java сервер

### Геолокация
- Автоматическое определение GPS координат
- Проверка нахождения в геозоне объекта
- Блокировка начала работы вне зоны

### Рабочий процесс
- **Начать день** - проверка геозоны, старт таймера
- **Перерыв 10 мин** - с 50 по 60 минуту каждого часа
- **Обед 1 час** - через 4 часа от начала смены
- **Завершить день** - загрузка фото, комментарий

### Напоминания
- ⏰ В 50 минут: "Через 10 минут перерыв!"
- ⏰ В 00 минут: "Пора приступить к работе!"
- Push-уведомления даже при закрытом приложении

### Фотоотчет
- До 10 фотографий выполненной работы
- Предпросмотр перед отправкой
- Комментарий к работе

## 🔧 Технические особенности

### Service Worker
- Кэширование приложения для офлайн работы
- Обработка push-уведомлений
- Быстрая загрузка при повторном открытии

### Manifest
- Установка на главный экран
- Полноэкранный режим (standalone)
- Иконки всех размеров

### Геолокация
- Высокоточный GPS (enableHighAccuracy)
- Постоянное отслеживание (watchPosition)
- Проверка расстояния до геозоны

## 🌐 API Endpoints

```
POST /api/employee/register          - Регистрация
POST /api/employee/start-work        - Начало дня
POST /api/employee/end-work          - Завершение дня
POST /api/employee/{id}/photo        - Загрузка фото
GET  /api/employee/{id}/tasks/today  - Задание на сегодня
```
