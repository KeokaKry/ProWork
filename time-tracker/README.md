# Система учета рабочего времени

## Описание
Приложение для учета рабочего времени сотрудников с возможностью отслеживания перерывов, обедов, загрузки фото выполненной работы и автоматического расчета зарплаты.

## Компоненты системы

### 1. Сервер (Backend)
- **Технологии**: Node.js, Express, SQLite
- **Порт**: 3000
- **Функции**:
  - Регистрация сотрудников
  - Отслеживание рабочих сессий
  - Хранение фотографий
  - Расчет зарплаты
  - Управление заданиями
  - Экспорт табелей

### 2. Приложение сотрудника
- **Файл**: `employee-app/index.html`
- **Функции**:
  - Регистрация нового сотрудника
  - Начало/окончание рабочего дня
  - Отметка перерывов и обеда
  - Загрузка фото выполненной работы
  - Добавление комментариев
  - Просмотр заданий на день
  - Напоминания о перерывах

### 3. Приложение администратора
- **Файл**: `admin-app/index.html`
- **Функции**:
  - Просмотр всех сотрудников
  - Установка почасовой ставки
  - Просмотр рабочих сессий с расчетом зарплаты
  - Просмотр фотографий
  - Наложение штрафов
  - Назначение заданий по дням недели
  - Экспорт табелей в CSV

## Установка и запуск

### 1. Установка зависимостей сервера
```bash
cd server
npm install
```

### 2. Запуск сервера
```bash
npm start
# или для разработки с автоперезагрузкой
npm run dev
```

### 3. Открытие приложений
- **Сотрудник**: Откройте `employee-app/index.html` в браузере
- **Администратор**: Откройте `admin-app/index.html` в браузере

## API Endpoints

### Сотрудник
- `POST /api/employee/register` - Регистрация
- `POST /api/employee/start-day` - Начало рабочего дня
- `POST /api/employee/end-day` - Окончание дня с фото
- `POST /api/employee/break-start` - Начало перерыва
- `POST /api/employee/break-end` - Конец перерыва
- `POST /api/employee/lunch-start` - Начало обеда
- `POST /api/employee/lunch-end` - Конец обеда
- `GET /api/employee/tasks/:employeeId` - Задания на сегодня
- `GET /api/employee/session/:employeeId` - Текущая сессия

### Администратор
- `GET /api/admin/employees` - Список сотрудников
- `PUT /api/admin/employee/:id/rate` - Обновление ставки
- `GET /api/admin/sessions` - Все сессии с зарплатой
- `GET /api/admin/photos/:sessionId` - Фото сессии
- `POST /api/admin/fine` - Наложить штраф
- `POST /api/admin/task` - Назначить задание
- `GET /api/admin/export-timesheet/:employeeId?` - Экспорт табеля

## Структура базы данных

### employees
- id, name, profession, hourly_rate, created_at

### work_sessions
- id, employee_id, date, start_time, end_time
- break_start, break_end, lunch_start, lunch_end
- total_hours, status, comment, fine_amount

### work_photos
- id, session_id, photo_path, uploaded_at

### tasks
- id, employee_id, day_of_week, description, created_at

## Возможности

### Для сотрудников:
✅ Регистрация с указанием профессии
✅ Отметка начала рабочего дня
✅ Таймер рабочего времени
✅ Перерывы и обед с отметками
✅ Загрузка фото выполненной работы
✅ Комментарии к работе
✅ Просмотр заданий на день
✅ Напоминания о перерывах каждый час
✅ Напоминание об обеде в 12:00

### Для администратора:
✅ Просмотр всех сотрудников
✅ Установка почасовой ставки по должности
✅ Автоматический расчет зарплаты
✅ Просмотр фото выполненной работы
✅ Скачивание фото
✅ Наложение штрафов
✅ Назначение заданий по дням недели
✅ Экспорт табелей в CSV (по сотруднику или всем)

## Примечания
- Фотографии сохраняются в папке `server/uploads`
- База данных SQLite создается автоматически при первом запуске
- Приложения работают в браузере и адаптированы для мобильных устройств
